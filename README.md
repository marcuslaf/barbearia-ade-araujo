# Barbearia AD Araújo

Site institucional da Barbearia AD Araújo, desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades

- **Navegação responsiva** com menu hamburger em dispositivos móveis
- **Seção de serviços** com grid responsivo
- **Galeria de fotos** com lightbox e navegação por setas/teclado
- **Formulário de contato** com validação e feedback visual
- **Scroll to top** para facilitar a navegação
- **SEO otimizado** com meta tags, Open Graph, Twitter Card e Schema.org
- **Acessível** com skip-link, aria labels, alt texts descritivos e prefers-reduced-motion

## Como rodar localmente

1. Clone o repositório
2. Abra o `index.html` em um navegador

## SEO

Para completar o SEO, substitua os seguintes valores no `index.html`:

- `https://seudominio.com/` → seu domínio real
- `+55-XX-XXXXX-XXXX` → seu telefone
- Endereço no Schema.org → seu endereço real
- Gere um `favicon.png` e coloque na pasta `Imagens/`

## Deploy

O site está configurado para deploy automático na Vercel.
